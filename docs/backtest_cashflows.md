# Backtest contributions, fixed fees and saved portfolios

Monthly DCA is optional and off by default. Initial capital funds the first executable period; contributions start in the following month of the selected test, with no retroactive contributions for unobserved periods. Deposits are external cash flows, not profit. Final wealth, total contributed (including initial capital) and investment gain are reported separately. CAGR, total return, volatility, drawdown and rolling returns use cash-flow-adjusted return indices, not account balance growth. Money-weighted IRR is not claimed.

Monthly strategies invest the contribution at their next execution boundary, before earning that holding period. Daily strategies add it at the first eligible session open of the month: existing holdings first earn overnight returns, deposits are added, orders execute, then intraday returns accrue. Mixed-frequency portfolios split deposits using configured sleeve weights: daily sleeves receive open contributions, monthly sleeves receive close contributions. Portfolio return measurement splits at the open cash flow and excludes close deposits; benchmark deposits match those same open/close timings. Opening quotes for all sleeves are required for mixed DCA. Monthly sleeve DCA purchases may trigger basket adjustments to its current target on the contribution close. No inter-sleeve transfers are introduced in mixed mode.

Synthetic daily NAV imports receive contributions before the first daily observation's return in each subsequent complete reporting month. This is a reporting-period proxy, not an executable open quote. The benchmark uses the matching monthly deposits. The earlier monthly-only daily-strategy import also supports DCA at reporting period boundaries. Their original tax/order-fee restrictions remain enforced and visible.

Choose percentage fees (the existing engine convention) or a fixed amount in backtest currency per buy/sell order. A complete switch normally produces two fixed-fee orders; unchanged holdings produce none, except contribution purchases. Basket orders are counted by asset/side, separately for each strategy sleeve; no broker netting across sleeves is claimed. Portfolio fixed fees are applied to funded positions, never the old one-unit sleeve simulations. Initial acquisitions incur fees; final liquidation is not forced. Fixed acquisition fees enter modeled tax bases and fixed sale fees reduce modeled realized proceeds. Infeasible capital/fee combinations are rejected. Existing percentage assumptions differ between legacy monthly one-way turnover and daily/mixed buy/sell-side engines; this change does not harmonize them silently. Benchmarks remain fee-free, disclosed beside DCA controls.

Monthly-only portfolios with DCA or fixed fees use one funded, security-level monthly target-weight book with sleeve-qualified asset roles. Sleeve targets are reset at each shared holding-period boundary. CGT is applied to actual modeled reductions in this combined book rather than scaling taxes from normalized sleeve simulations. Legacy monthly-only portfolios with both additions off retain their existing path. Deep History uses the same book but security returns there are strategy-level allocation proxies, so CGT remains approximate. Per-sleeve unit returns in advanced monthly portfolios exclude aggregate fixed fees. Mixed portfolios retain separate sleeve tax bases and loss carryforwards; account-wide tax netting remains outside scope.

Backtest Portfolio mode can load a named browser portfolio or a version-1 JSON exported from Portfolio. Validation rejects unknown strategies, non-positive/non-finite weights, weights not totaling 100%, invalid capital/FX and oversized device files. Loading is applied on the next rerun before widget creation, clears only backtest sleeve selection state, and does not overwrite the Today default or portfolio library. Saved ILS capital is converted to USD using the saved FX rate; this is configuration funding, not historical FX modeling. Backtest availability and currency restrictions continue to be enforced by the selected engines. Files do not execute code.
